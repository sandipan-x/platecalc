# PlateCalc

Free barbell plate calculator: enter your target weight for exact plates per side, warm-up sets and a visual loading diagram. Works in lb and kg.

## Features
- Per-side plate breakdown with greedy largest-first loading and remainder reporting
- Bar weight selector (45 / 35 / 20) with lb–kg unit toggle
- Warm-up set generator with loadable rounded weights plus a visual barbell diagram
